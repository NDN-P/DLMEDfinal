• วัตถุ-กับ-เซลล์ : วัตถุหนึ่งชิ้นถูกกําหนดให้กับเซลล์ที่มีจุดกึ่งกลางของวัตถุ ตกอยู่

2. ทําแบบ Label ให้อยู่ในรูปแบบของ YOLO
ฉลากข้อมูลสําหรับ YOLO จะอยู่ในรูปแบบของไฟล์ .txt 
(1 ไฟล์เฉลยสําหรับต่อ 1 ภาพ) โดยที่ ข้อมูลภายในไฟล์จะ
มีลักษณะการจัดเก็บเป็น “หนึ่งแถวต่อวัตถุหนึ่งชิ้น” และใน 
1 แถว จะประกอบด้วยข้อมูลดังนี้ 
• ประเภท (Class), 
• จุด x_center,
• จุด y_center, 
• ความกว้างของวัตถุ
• ความสูงของวัตถุ
จากนั้น ตําแหน่งจะต้องถูก Normalize ให้อยู่รูปแบบ 0 – 
1 โดยใช้ขนาดของภาพ ซึ่งมุมบนซ้ายของภาพ แทน จุด (0, 
0) และมุมล่างขวา แทน จุด (1, 1)

from ultralytics import YOLO
import yaml
# Initialize the model
model = YOLO("yolov8n.pt")
# Train the model with your custom dataset
results = model.train(data="mock_data_file.yaml", epochs=5, batch=16, imgsz=256)
print("Training completed")

6. การทดสอบและวัดผลโมเดล
สําหรับวิธีการทดสอบและวัดผล YOLO สามารถทําได้โดยการสร้างไฟล์ .py จากนั้น ใส่ที่อยู่ของโมเดลที่ฝึกสอนแล้ว และเรียกใช้ฟังก์ชัน val() 
จากโมเดลได้เลย พร้อมกับกําหนดรายละเอียดพารามิเตอร์ต่าง ๆ 
วิธีการฝึกฝน Ultralytics YOLOv8 ด้วยชุดข้อมูลกําหนดเอง
./datasets/coco128/images/train2017/im0.jpg
from ultralytics import YOLO
# Load a model
model = YOLO("runs/detect/train/weights/best.pt")
# Customize validation settings
validation_results = model.val(data="mock_data_file.yaml", imgsz=256, batch=16, conf=0.25, 
iou=0.5)
• batch คือ การส่งรูปให้โมเดลครั้งละหลายรูป ซึ่งสามารถส่งไปฝึกสอนหรือทดสอบครั้งละหลายรูปได้
• conf คือ confidence score ที่ใช้ขจัด Object ที่มีความมั่นใจตํ่าออกไป โดยปกติโปรแกรมได้กําหนดค่าเริ่มต้นเป็น 0.001 (ไม่แนะนํา)
• iou คือ เกณฑ์ในการพิจารณาการซ้อนทับกันของวัตถุในขั้นตอน non-maximize suppression โดยปกติโปรแกรมได้กําหนดค่าเริ่มต้นเป็น 0.6

img = cv2.imread(img_path)
# Run inference
results = model(img)

    # Save the result image with predictions
    output_img_path = os.path.join(output_path, img_name)
    result.save(output_img_path)
เนื่องจากชุดคําสั่ง Ultralytics YOLOv8 รองรับการทํางานทั้ง object detection และ segmentation ส่งผลให้เวลาคืนค่าตัวแปร result จะให้ผลลัพธ์ออกมา
ทั้ง 2 แบบ ดังนั้น ชุดคําสั่ง Ultralytics YOLOv8 จึงเก็บผลลัพธ์ในรูปแบบ List 
แต่อย่างไรก็ตาม ถ้านักศึกษาต้องการผลลัพธ์เฉพาะ object detection 
สามารถแก้ไขโค้ดบริเวณสีเหลืองเป็น output_img_path = os.path.join(output_path, img_name) และ result[0].save(output_img_path)
