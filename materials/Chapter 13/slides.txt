ข้อมูลแบบอนุกรมเวลา (Time Series) 
คือ ชุดข้อมูลที่บันทึกในช่วงเวลาต่อเนื่องกัน โดยข้อมูลแต่ละตัวจะถูกจัดเก็บตามลําดับ
เวลา ข้อมูลเหล่านี้มักจะใช้ในการวิเคราะห์แนวโน้ม (Trend Analysis) และรูปแบบที่
เกิดขึ้นตามเวลา (Seasonal Analysis) รวมถึงการทํานายค่าในอนาคต (Forecasting)
ตัวอย่างทั่วไปของข้อมูลแบบอนุกรมเวลา ได้แก่ ข้อมูลราคาหุ้น, ข้อมูลอุณหภูมิ, ข้อมูล
การผลิตสินค้าในโรงงาน, และข้อมูลผู้เข้าชมเว็บไซต์ในแต่ละวัน
• ราคาหุ้น (Stock 
Prices): ข้อมูลราคาหุ้นจะถูกบันทึกในทุกๆ วันหรือทุกๆ นาที 
ขึ้นอยู่กับความถี่ในการซื้อขาย
• อุณหภูมิรายวัน (Daily 
Temperature): ข้อมูลอุณหภูมิที่วัดได้ในแต่ละวัน 
ตัวอย่างเช่น อุณหภูมิสูงสุดในกรุงเทพฯ ในแต่ละวัน
• ปริมาณการขายสินค้า (Sales 
Volume): ข้อมูลจํานวนสินค้าที่ขายได้ในแต่ละ
เดือน ตัวอย่างเช่น จํานวนเครื่องใช้ไฟฟ้าที่ขายได้ในแต่ละเดือน

ข้อมูล Time Series สําหรับวิดีโอ
คือ การใช้ข้อมูลแบบอนุกรมเวลา (Time 
Series) 
สําหรับวิดีโอเป็นการวิเคราะห์ข้อมูลที่
เกี่ยวข้องกับลําดับของเฟรมที่เกิดขึ้นตามเวลา ซึ่งเป็นข้อมูลที่มีความซับซ้อนมากกว่าข้อมูลแบบ
อนุกรมเวลาทั่วไป เนื่องจากประกอบด้วยทั้งข้อมูลเชิงพื้นที่ (spatial data) และข้อมูลเชิงเวลา 
(temporal data)
ตัวอย่างการใช้งาน 
• การตรวจจับการกระทํา (Action Recognition): วิดีโอที่บันทึกการเล่นกีฬาจะมีลําดับของ
เฟรมที่แสดงการเคลื่อนไหวต่างๆ การวิเคราะห์ข้อมูลนี้สามารถใช้ในการตรวจจับการกระทํา 
เช่น การเตะบอล การกระโดด หรือการหมุนตัว
• การตรวจจับเหตุการณ์ (Event Detection): ใช้ในการตรวจจับเหตุการณ์เฉพาะในวิดีโอ 
เช่น การตรวจจับการชนในวิดีโอจากกล้องวงจรปิด หรือการตรวจจับการล้มของผู้สูงอายุ ซึ่ง
สามารถใช้งานโมเดล Convolutional Neural Networks (CNN) ร่วมกับ Recurrent 
Neural Networks (RNN) หรือ Long Short-Term Memory (LSTM)
• การวิเคราะห์พฤติกรรม (Behavior Analysis): ใช้ในการวิเคราะห์พฤติกรรมของบุคคลหรือ
วัตถุในวิดีโอ เช่น การวิเคราะห์พฤติกรรมการเดินของผู้คนในสถานีรถไฟ ซึ่งสามารถใช้งาน

ในการประมวลผลข้อมูลประเภทวิดีโอ เราจําเป็นต้องพิจารณาลักษณะเชิงพื้นที่ (Spatial Feature) และลักษณะเชิง
เวลา (Temporal Feature) พร้อมกัน เนื่องจากวิดีโอเป็นการรวมกันของภาพที่ต่อเนื่องกันซึ่งมีข้อมูลทั้งสองมิติอยู่
• Spatial Feature เป็นลักษณะเชิงพื้นที่คือข้อมูลที่เกี่ยวข้องกับรายละเอียดภายในแต่ละเฟรมของวิดีโอ ซึ่งเป็น
ข้อมูลที่บอกถึงโครงสร้างและลักษณะเฉพาะของวัตถุภายในภาพ เช่น ขอบเขต สี รูปร่าง และพื้นผิว ซึ่งสามารถ
สกัดด้วยเทคนิค Convolutional Neural Networks (CNNs) ซึ่งใช้ฟิลเตอร์คอนโวลูชันเพื่อดึงลักษณะต่างๆ จาก
ภาพ 
• Temporal 
Feature เป็นลักษณะเชิงเวลาคือข้อมูลที่เกี่ยวข้องกับการเปลี่ยนแปลงของภาพในแต่ละเฟรมเมื่อ
เทียบกับเฟรมก่อนหน้า เป็นการบ่งบอกถึงความสัมพันธ์และการเคลื่อนไหวของวัตถุภายในวิดีโอ ซึ่งสามารถสกัด
ลักษณะเชิงเวลามักจะใช้เทคนิค Recurrent Neural Networks (RNNs) หรือ Long Short-Term Memory 
(LSTM) ซึ่งเหมาะสมกับการจัดการข้อมูลที่มีลําดับเวลา
การรวมสกัดคุณลักษณะทางด้าน Spatial และ Temporal ร่วมกันจากวิดีโอที่ซับซ้อนมักจะใช้การผสมผสานระหว่าง 
CNNs และ LSTMs เพื่อสกัดลักษณะเชิงพื้นที่จากแต่ละเฟรม และใช้ LSTMs เพื่อจับความสัมพันธ์เชิงเวลาในเฟรม
ต่อเนื่อง นอกจากนี้ ยังมีเทคนิค 3D Convolutional Networks (3D CNNs) ที่ใช้ฟิลเตอร์สามมิติในการจับลักษณะ
เชิงพื้นที่และเชิงเวลาในครั้งเดียว

โครงข่ายประสาทแบบวนกลับ 
สถาปัตยกรรม Neural Network (NN) และ Convolution Neural 
Network (CNN) ได้รับการออกแบบให้มีความเหมาะสมกับ 
• อินพุตที่ใส่ค่าเข้ามาพร้อมกันทั้งหมด อาทิเช่น รับค่าพิกเซลเข้ามาทั้งภาพ หรือ 
รับค่าของคุณลักษณะเข้ามาทั้งเวกเตอร์ เป็นต้น
• อินพุตต้องไม่มีความสัมพันธิเชิงลําดับ (Sequence) ที่ส่งผลต่อการทํานาย
ผลลัพธ์
• อินพุตต้องมีขนาดที่เท่ากันและแน่นอน 
ดังนั้น สถาปัตยกรรม NN และ CNN จึงไม่เหมาะสมกับข้อมูลที่มี
ความสัมพันธ์ในลําดับก่อนหลัง และไม่รองรับข้อมูลที่มีขนาดไม่เท่ากัน
(ก) สถาปัตยกรรม NN
(ข) สถาปัตยกรรม RNN
--- page 19 ---
โครงข่ายประสาทแบบวนกลับ 
เพื่อจะสามารถสร้างแบบจําลองที่รองรับข้อมูลที่มีขนาดไม่เท่ากันและเหมาะสมกับ
ข้อมูลที่มีความสัมพันธ์เชิงลําดับ(หรือเรียกว่า ข้อมูลอนุกรมเวลา) ดังนั้น จึงได้มีการ
นําเสนอสถาปัตยกรรมแบบโครงข่ายประสาทแบบวนกลับ (Recurrent 
Neural 
Network: RNN)
ข้อมูลที่มีความสัมพันธ์เชิงลําดับ (หรือ สถานะ/state/ความรู้ก่อนหน้า) มี
ความสําคัญต่อแบบจําลองเป็นอย่างมาก แต่จะพบว่าสถาปัตยกรรม NN ไม่มีการ
เก็บสารสนเทศก่อนหน้า (หรือ สถานะก่อนหน้า) เอาไว้ ขณะที่ สถาปัตยกรรมRNN 
มีการเก็บสารสนเทศของสารสนเทศก่อนหน้าไว้ (เส้นสีม่วง) และนํามาประมวลผล
ร่วมกับข้อมูลปัจจุบัน สิ่งเหล่านี้ทําให้ RNN เป็นสถาปัตยกรรมที่ได้ทํานายผลลัพธ์
มาจากข้อมูล 2 แหล่ง ได้แก่ ข้อมูลปัจจุบันและสารสนเทศของสถานะก่อนหน้า
(ก) สถาปัตยกรรม NN
(ข) สถาปัตยกรรม RNN

โครงข่ายประสาทแบบวนกลับ 
โครงข่ายประสาทแบบวนกลับเป็นสถาปัตยกรรมที่ได้รับการออกแบบมาเพื่อให้ใช้
งานกับข้อมูลที่เป็นลําดับ (Sequence) ได้แก่ วีดิโอ (Video or Sequence of 
Images) หรือ ข้อความ (Text or Sequence of Words) เป็นต้น RNN มีลักษณะ
การทํางานคล้ายกับพฤติกรรมการอ่านหนังสือของมนุษย์ โดยที่ มนุษย์จะอ่าน
หนังสือทีละคํา เพื่อทําความเข้าใจเรื่องราวที่อ่าน ซึ่งมนุษย์สามารถเข้าใจเรื่องราวที่
อ่านได้เนื่องจากมีข้อมูลของคําที่อ่านก่อนหน้ามาแล้วและผนวกกับคําที่เรากําลังอ่าน
อยู่ ณ ตําแหน่งปัจจุบัน สิ่งเหล่านี้ทําให้มนุษย์เข้าใจความหมายของสิ่งที่อ่านเข้าไป 
ดังนั้น RNN จึงได้รับการออกแบบให้มีสถาปัตยกรรมที่มีการพิจารณา (1) 
สารสนเทศก่อนหน้า (Previous Information) และ (2) ข้อมูล ณ ตําแหน่งปัจจุบัน 
เพื่อให้สามารถทําความเข้าใจข้อมูลและสิ่งที่ต้องการทํานายได้

Unfold
(ขยายออกมา)
จากตัวอย่างข้างต้น นักศึกษาจะพบว่า Hidden Layer (หรือ เรียกได้ว่า RNN Cell) มีเพียงตัวเดียว แต่สามารถ Unfold ออกมา
เพื่อให้เห็นการทํางานในแต่ละรอบได้ ซึ่งจากตัวอย่างได้แสดงให้เห็นการทํางาน 3 รอบ “A recurrent neural network can 
be seen as the repeated use of a single RNN Cell. ”

โครงข่ายประสาทแบบวนกลับ 
เมื่อพิจารณาภายใน RNN Cell (หรือ Hidden Layer: H) จะพบว่า
คุณลักษณะหรือสารสนเทศที่สําคัญจะคํานวณมาจาก 2 ส่วน ได้แก่
• ส่วนข้อมูล ณ เวลา ปัจจุบัน (Xt )
• ส่วนข้อมูลที่ได้รับการประมวลผลก่อนหน้า (Ht-1 )
โดยที่ Xt จะถูกควบคุมการไหล่เข้าสู่ RNN Cell ด้วย Wxt ขณะที่ 
Ht-1 จะถูกควบคุมการไหล่เข้าสู่ RNN Cell ด้วย Wht ซึ่งคุณลักษณะ
หรือสารสนเทศที่ได้รับจาก RNN Cell จะคํานวณได้จากสมการ
ต่อไปนี้
Ht = Tanh(   Xt ⋅ Wxt       +  Ht-1 ⋅ Wht     + Bt )

และสามารถคํานวณผลลัพธ์ของ RNN Cell ได้จากสมการต่อไปนี้ 
Yt = Softmax(   Ht ⋅ Wyt       +  Byt     )
โดยที่ Wyt มีหน้าที่ควบคุมการไหล่ของสารสนเทศออกจาก RNN

class VideoDataset(Dataset):
   def load_video(self, path):
        cap = cv2.VideoCapture(path)
        frames = []
        try:
            while True:
                ret, frame = cap.read()
# Stop condition when failing to read
                if not ret: 
                    break
# Preprocess Option
                if self.resize:
                    frame = cv2.resize(frame, self.resize)
                frames.append(frame)
# Stop condition when the number of maximum frames equals 
# the number of frames read from the video
                if self.max_frames and (len(frames) >= self.max_frames):
                    break
        finally:
            cap.release()
        return np.array(frames)

class ConvLSTMCell(nn.Module):
    def __init__(self, input_dim, hidden_dim, kernel_size, bias):
        super(ConvLSTMCell, self).__init__()
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        self.kernel_size = kernel_size
        self.padding = kernel_size[0] // 2, kernel_size[1] // 2
        self.bias = bias
        self.conv = nn.Conv2d(in_channels=self.input_dim + self.hidden_dim,
out_channels=4 * self.hidden_dim,
                              kernel_size=self.kernel_size,
padding=self.padding,
bias=self.bias)
    def forward(self, input_tensor, cur_state):
        h_cur, c_cur = cur_state
        combined = torch.cat([input_tensor, h_cur], dim=1)  # concatenate along channel axis
        combined_conv = self.conv(combined)
        cc_i, cc_f, cc_o, cc_g = torch.split(combined_conv, self.hidden_dim, dim=1)
        i = torch.sigmoid(cc_i)
        f = torch.sigmoid(cc_f)
        o = torch.sigmoid(cc_o)
        g = torch.tanh(cc_g)
        c_next = f * c_cur + i * g
        h_next = o * torch.tanh(c_next)
        return h_next, c_next

import numpy as np
import cv2
def load_video(path, resize, max_frames):
        cap = cv2.VideoCapture(path)
        frames = []
        try:
            while True:
                ret, frame = cap.read()
                if not ret:
                    break
                if resize:
                    frame = cv2.resize(frame, resize)
                frames.append(frame)
                if max_frames and len(frames) >= max_frames:
                    break
        finally:
            cap.release()
        return np.array(frames)

ตัวอย่างการเรียกใช้งาน
จากคําสั่งm = nn.Conv3d(16, 33, 3, stride=2) ของPyTorch เป็นการสร้างเลเยอร์การคอนโวลูชัน3 มิติ(3D Convolutional Layer) ซึ่งมี
พารามิเตอร์ต่างๆที่กําหนดลักษณะการทํางานของเลเยอร์ดังนี้
• 16 คือจํานวนช่องอินพุต(input channels) ของข้อมูลที่เข้าสู่เลเยอร์คอนโวลูชัน
• 33 คือจํานวนช่องเอาท์พุต(output channels) หรือจํานวนฟิลเตอร์ที่เลเยอร์คอนโวลูชันจะสร้างขึ้น
• 3 คือขนาดของเคอร์เนล(kernel size) หรือฟิลเตอร์ที่ใช้ในคอนโวลูชันซึ่งในที่นี้คือ3 × 3 × 3
• stride=2 คือ กําหนดขนาดของการก้าวข้าม(stride) ของฟิลเตอร์ในทุกมิติ
# With square kernels and equal stride
m = nn.Conv3d(16, 33, 3, stride=2)
# non-square kernels and unequal stride and with padding
m = nn.Conv3d(16, 33, (3, 5, 2), stride=(2, 1, 1), padding=(4, 2, 0))
input = torch.randn(20, 16, 10, 50, 100)
output = m(input)

สถาปัตยกรรม Inflated 3D ConvNet
qInflation (ขยายเป็น 3D)
• เริ่มจากโครงสร้าง ConvNet 2D ที่ออกแบบดีแล้ว (Inception-v1)
• แปลงตัวคอนโวลูชันฟิลเตอร์และการ pooling ที่เดิมเป็น 2D (ขนาด N × N) ให้กลายเป็น 3D ที่มีขนาด T × N × N โดย T คือความยาวในมิติเวลาหนึ่ง
• จุดสําคัญคือ การเลือกว่า temporal stride / temporal pooling จะเป็นอย่างไร เพื่อให้ receptive field ทางเวลาเหมาะสม

สถาปัตยกรรม Inflated 3D ConvNet
qตัวดําเนินการ 1×1×1 convolution ใน I3D 
ใช้ 3D convolution ซึ่ง filter มี 3 มิติ ได้แก่
• T = temporal (เวลา, กี่ frame ต่อ kernel)
• H, W = spatial (ความสูง × ความกว้างของภาพ)
ดังนั้น 1×1×1 convolution หมายถึง kernel ขนาด 
• Temporal size = 1 (ไม่ครอบเวลา, ใช้ frame เดียวในเชิงเวลา)
• Spatial size = 1×1 (ไม่ครอบพื้นที่, ใช้ pixel ตรงตําแหน่งเดียว)
สรุป มันไม่ “มองพื้นที่” และไม่ “มองเวลา” แต่ทําการ linear combination ของ channels เท่านั้น
qบทบาทของตัวดําเนินการ 1×1×1 convolution ใน I3D 
ทําหน้าที่คล้าย 1×1 conv ในโมเดล 2D แต่ขยายสู่ 3D เพื่อ
• Channel reduction ทําให้ลด computation, memory
• Channel mixing รวมข้อมูลจากหลาย channel feature ให้เกิดการผสม (linear 
combination) ทําให้โมเดลเรียน feature representation ที่มีความหมายใหม่ ๆ ได้
• Non-linearity เมื่อทํางานร่วมกับ ReLU และ BatchNorm จะเพิ่มความซับซ้อนของฟังก์ชัน
ที่เรียนรู้
• Flexibility ในการออกแบบ Inception branch เพื่อให้ได้ feature “สั้นและเบา”
