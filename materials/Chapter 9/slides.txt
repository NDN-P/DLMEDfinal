Multiclass Image Classification 
Multiclass Image Classification (การจําแนกภาพแบบหลายคลาส)
เป็นการจําแนกภาพออกเป็นคลาสต่าง ๆ ที่ไม่ทับซ้อนกัน (หนึ่งภาพเป็นเพียงหนึ่งคลาส) เช่น การจําแนกรูปภาพของสัตว์ โดยแต่ละภาพเป็นสุนัข แมว 
หรือม้า นิยมใช้ในงานที่ภาพแต่ละภาพสามารถถูกจัดอยู่ในคลาสเดียว เช่น การจําแนกประเภทของดอกไม้, การจําแนกประเภทของยานพาหนะ
--- page 6 ---
Multilabel Image Classification 
Multilabel Image Classification (การจําแนกภาพแบบหลายป้ายชื่อ)
เป็นการจําแนกภาพออกเป็นหลายคลาสที่สามารถทับซ้อนกันได้ (หนึ่งภาพสามารถอยู่ในหลายคลาส) เช่น การจําแนกรูปภาพที่อาจมีทั้งแมวและสุนัขใน
ภาพเดียวกัน ดังนั้น ภาพหนึ่งสามารถมีหลายป้ายชื่อ นิยมใช้ในงานที่ภาพแต่ละภาพสามารถถูกจัดอยู่ในหลายคลาส เช่น การจําแนกวัตถุในภาพที่อาจมีทั้ง
รถยนต์ คน และต้นไม้ในภาพเดียวกัน หรือการบอกชนิดของภาพยนต์จากโปสเตอร์

Multi-task Learning (การเรียนรู้หลายงานพร้อมกัน)
Multi-task 
Learning เป็นการฝึกโมเดลเดียวให้
สามารถทํานายผลได้หลายอย่างพร้อมกัน โดยมี
หลายคําถาม (tasks) ในการทํานายแต่ละครั้ง อาทิ
เช่น
• ทํานายชนิดของผลไม้ เช่น แอปเปิ้ล, กล้วย, ส้ม
• ทํานายสถานะของผลไม้ เช่น เน่าหรือไม่เน่า
ประโยชน์ของการเรียนรู้หลายงานพร้อมกัน
• ประหยัดทรัพยากร: ไม่ต้องฝึกโมเดลแยกกัน
สําหรับแต่ละงาน ทําให้ประหยัดเวลาและ
พลังงานในการคํานวณ
• เรียนรู้ร่วมกัน: โมเดลสามารถใช้ข้อมูลร่วมกัน
เพื่อพัฒนาความแม่นยําในการทํานายแต่ละงาน

Multi-task Learning (การเรียนรู้หลายงานพร้อมกัน)
สาระสําคัญบางประการที่ควรพิจารณาเมื่อใช้งานการเรียนรู้หลายงานพร้อมกัน (Multi-Task Learning) สําหรับการเรียนรู้เชิงลึก:
• ความเกี่ยวข้องของงาน: Multi-Task Learning จะมีประสิทธิภาพสูงสุดเมื่อหลายงานมีความเกี่ยวข้องหรือมีบางอย่างที่เหมือนกัน 
• ข้อจํากัดของข้อมูล: Multi-Task 
Learning 
สามารถมีประโยชน์เมื่อข้อมูลมีจํากัด เนื่องจากช่วยให้โมเดลสามารถใช้ข้อมูลที่แชร์ร่วมกัน
ระหว่างงานเพื่อปรับปรุงประสิทธิภาพของโมเดลได้
• การสกัดคุณลักษณะร่วมกัน (Shared Feature Extractor): Multi-Task Learning มักมีการใช้งาน Feature Extraction ร่วมกัน ซึ่งเป็น
ส่วนหนึ่งของเครือข่ายที่ใช้ร่วมกันระหว่างงาน
• การตัดสินใจเฉพาะงาน (Task-specific Heads): Multi-Task Learning มักจะใช้ neural network เฉพาะงาน กล่าวคือ neural 
network หนึ่งเครือข่ายใช้ในการทํานายต่อหนึ่งงาน และมักจะเชื่อมต่อกับตัว Feature Extraction ที่สกัดคุณลักษณะข้อมูลร่วมกัน
• การตัดสินใจร่วม (Shared Decision-making Layer): อีกวิธีหนึ่งคือการใช้ชั้นการตัดสินใจร่วม โดยใช้ส่วนของ Feature Extraction
และ Neural Network ร่วมกันระหว่างงาน และชั้นเฉพาะงาน แต่ Output Layer (Layer สุดท้าย) จะใช้เฉพาะงาน

Multi-task Learning (การเรียนรู้หลายงานพร้อมกัน)
การออกแบบสถาปัตยกรรมของ Multi-Task Learning ควรถูกออกแบบอย่างรอบคอบเพื่อรองรับงานต่าง ๆ และเพื่อให้แน่ใจว่าคุณลักษณะที่
แชร์ร่วมกันนั้นมีประโยชน์สําหรับทุกงาน และหลีกเลี่ยงการถ่ายโอนที่เป็นลบ (Negative Transfer) เมื่อหลายงานมีความแตกต่างกันมากหรือ
เป็นอิสระกัน Multi-Task Learning อาจนําไปสู่ประสิทธิภาพที่ไม่ดีเมื่อเทียบกับการฝึกโมเดลสําหรับงานเดียว ดังนั้น จึงเป็นเรื่องสําคัญที่จะต้อง
ทําให้แน่ใจว่าคุณลักษณะที่แชร์ร่วมกันนั้นมีประโยชน์สําหรับทุกงาน
